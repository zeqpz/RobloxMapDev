## Build order for every building (owner rule)
1. **Massing**: walls, roof, floor slabs, openings cut, R6-checked doors (4.6 x 7.4 x 0.5), parking + alleys on the lot.
2. **Trim pass**: door/window frames, sills, lintels, corner boards/quoins, parapet caps, roof edges, fascia,
   base/plinth bands, floor/slab edges, canopy trim.
3. **Character pass**: sun-faded paint, stains and drips, patched stucco, signs (fictional), AC units, satellite
   dishes, security bars, graffiti on rough blocks, clutter (barrels, dumpsters, junk), plants (yucca, juniper).
